# ESP32-S3 Smart Home Automation

## 📌 Project Overview

This project is an IoT-based Smart Home Automation system developed using the ESP32-S3 microcontroller and Blynk IoT platform. The system allows users to monitor and control home appliances remotely through a mobile application.

The project integrates multiple sensors and actuators to provide automation, monitoring, and safety features.

## 🚀 Features

* Remote control of home appliances using Blynk IoT
* Light control
* Door lock control using a solenoid lock
* Automatic and manual fan control
* Water solenoid valve control
* Temperature and humidity monitoring
* PIR motion detection
* Gas leakage monitoring using MQ-2 sensor
* Flame detection for fire safety
* Water level monitoring
* Buzzer-based safety alerts
* Real-time sensor data monitoring through Blynk IoT

## ⚙️ Working Principle

The ESP32-S3 acts as the main controller of the Smart Home Automation system. It collects data from various sensors and sends the information to the Blynk IoT platform through Wi-Fi.

Users can remotely control the light, door lock, fan, and water valve using the Blynk mobile application.

The DHT11 sensor monitors temperature and humidity. The PIR sensor detects motion. Based on motion detection and temperature conditions, the system can automatically control the fan.

The MQ-2 gas sensor detects gas leakage, while the flame sensor monitors fire conditions. When a safety condition is detected, the system activates the buzzer and sends alerts through the IoT platform.

The water level sensor monitors the water level, and the water solenoid valve can be controlled remotely.
